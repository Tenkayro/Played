# Contributing to Played

Contributions are welcome through the official repository:

<https://github.com/Zorblock/Played>

## Contribution process

1. Create a GitHub fork only for preparing your contribution.
2. Do not publish releases, packages, compiled JARs, or standalone distributions from the fork.
3. Make a focused change and test it locally with `./gradlew build` or `gradlew.bat build` on Windows.
4. Submit the change as a pull request to the official repository.
